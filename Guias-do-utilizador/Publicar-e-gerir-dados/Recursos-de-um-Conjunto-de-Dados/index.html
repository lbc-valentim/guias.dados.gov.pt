Recursos de um Conjunto de Dados

Disponibilize os dados através de ficheiros ou ligações e mantenha os recursos actualizados.

Para gerir recursos, inicie sessão como Editor ou Administrador com permissão sobre o Conjunto de Dados.

Descarregar este guia em PDF

O que pretende fazer?

Adicionar ficheirosCada ficheiro aceite origina um recurso próprio.Adicionar uma ligaçãoUse um recurso remoto quando os dados são disponibilizados noutro endereço.Editar metadados ou uma ligaçãoActualize a descrição do recurso ou o endereço de acesso quando necessário.Substituir o ficheiro de um recursoSubstitua o conteúdo quando pretende actualizar o ficheiro do mesmo recurso.Remover um recursoConfirme qual o recurso que pretende retirar antes de concluir.Consultar o recurso disponibilizadoVerifique como os dados são apresentados a quem os consulta.

Exemplo

Carregue dois ficheiros com dados de anos diferentes e atribua a cada recurso um título que identifique o ano correspondente.

Escolher a API adequada

A API do portal dá acesso programático ao catálogo. Uma API registada no catálogo tem o seu próprio endereço e documentação, que deve consultar antes de a utilizar.

Consulta pública

Como fazer

  1. Se pretende consultar ou integrar informação do catálogo, abra a referência da API do dados.gov.pt na área de desenvolvimento.
  2. Se procura uma API disponibilizada por uma entidade, consulte o seu registo no catálogo.
  3. Leia a descrição e a documentação associada para confirmar se a API responde à sua necessidade.
  4. Distinga o endereço da página no portal da URL base usada para comunicar com a API.

Exemplo

Uma equipa consulta a API do portal para recolher metadados do catálogo. Para usar um serviço de uma entidade, consulta a documentação ligada ao respectivo registo.

Imagem ou vídeo previsto

Referência da API do portal e registo de uma API, com os destinos identificados.

Dica

Registar uma API no catálogo não substitui a preparação e disponibilização do serviço pela entidade responsável.

01
Tarefa 1 de 6

Escolher a API adequada

A API do portal dá acesso programático ao catálogo. Uma API registada no catálogo tem o seu próprio endereço e documentação, que deve consultar antes de a utilizar.

Objectivo desta tarefaA API do portal dá acesso programático ao catálogo. Uma API registada no catálogo tem o seu próprio endereço e documentação, que deve consultar antes de a utilizar.

Como fazer

  1. 1Se pretende consultar ou integrar informação do catálogo, abra a referência da API do dados.gov.pt na área de desenvolvimento.
  2. 2Se procura uma API disponibilizada por uma entidade, consulte o seu registo no catálogo.
  3. 3Leia a descrição e a documentação associada para confirmar se a API responde à sua necessidade.
  4. 4Distinga o endereço da página no portal da URL base usada para comunicar com a API.
Exemplo

Uma equipa consulta a API do portal para recolher metadados do catálogo. Para usar um serviço de uma entidade, consulta a documentação ligada ao respectivo registo.

Dica

Registar uma API no catálogo não substitui a preparação e disponibilização do serviço pela entidade responsável.

02
Tarefa 2 de 6

Consultar a referência da API do portal

A referência permite identificar as operações disponíveis, os parâmetros e a informação devolvida.

Objectivo desta tarefaA referência permite identificar as operações disponíveis, os parâmetros e a informação devolvida.

Como fazer

  1. 1Se está a começar, percorra o tutorial da API; utilize a referência para consultar operações e parâmetros.
  2. 2Abra a referência da API do portal e consulte a documentação interactiva ou a ligação para Swagger.
  3. 3Localize a operação pretendida e leia os parâmetros e a estrutura da resposta.
  4. 4Para leitura de informação pública, siga a operação de consulta documentada. Quando a resposta for paginada, consulte as páginas seguintes indicadas na própria resposta.
  5. 5Para operações de escrita, obtenha uma chave nas definições do perfil e forneça-a no cabeçalho X-API-KEY. As permissões da conta continuam a aplicar-se.
  6. 6Se precisar da definição da API nas suas ferramentas, utilize a opção de descarregar a especificação OpenAPI em JSON.
  7. 7Antes de alterar ou eliminar conteúdos, reveja o pedido: o tutorial alerta que estas operações são definitivas e não disponibiliza uma área de testes.
Exemplo

Uma equipa consulta os metadados de organizações e percorre as páginas devolvidas para obter os restantes resultados.

Dica

Guarde a chave de forma reservada. Não a inclua em exemplos partilhados, capturas ou pedidos de apoio. Nos resultados paginados, next_page e previous_page indicam os endereços de navegação; null indica que não existe página nesse sentido.

03
Tarefa 3 de 6

Consultar uma API do catálogo

O registo reúne a descrição da API e as ligações que ajudam a compreender o serviço e os dados associados.

Objectivo desta tarefaO registo reúne a descrição da API e as ligações que ajudam a compreender o serviço e os dados associados.

Como fazer

  1. 1Abra o detalhe da API que pretende conhecer.
  2. 2Leia a descrição, a documentação funcional e a informação de acesso apresentada.
  3. 3Consulte a URL base e, quando disponível, a documentação Swagger para preparar a integração.
  4. 4Na área de informações, abra os Conjuntos de Dados associados que pretende consultar.
  5. 5Consulte as informações técnicas do registo, incluindo identificador, data de criação e última actualização.
Exemplo

Uma pessoa abre o detalhe de uma API e consulta um dos Conjuntos de Dados relacionados antes de preparar a integração.

Dica

A data de actualização do registo não confirma, por si só, a actualização de todos os dados devolvidos pelo serviço.

04
Tarefa 4 de 6

Preparar e registar uma API

A criação de uma API no catálogo é feita em nome de uma organização com o emblema Serviço público da qual o utilizador seja membro. Esta regra também se aplica a administradores do portal.

Objectivo desta tarefaA criação de uma API no catálogo é feita em nome de uma organização com o emblema Serviço público da qual o utilizador seja membro. Esta regra também se aplica a administradores do portal.

Como fazer

  1. 1Confirme que pertence à organização que vai publicar a API e que esta tem o emblema Serviço público.
  2. 2Prepare a descrição do serviço, a URL base, as ligações de documentação e as condições de acesso.
  3. 3Inicie a criação de uma API e seleccione a organização elegível no campo Produtor.
  4. 4Preencha a informação pedida no formulário. No tipo de acesso, escolha Aberto, Aberto com conta ou Restrito de acordo com o serviço. Para acesso restrito, prepare as audiências, condições e motivo da restrição.
  5. 5No passo de associação de Conjuntos de Dados, seleccione os que correspondem ao serviço. Esta associação é opcional.
  6. 6No passo final, escolha guardar como rascunho ou publicar. Consulte a listagem para confirmar o resultado.
Exemplo

Uma organização com o emblema Serviço público prepara o registo da sua API, associa um Conjunto de Dados e guarda o rascunho para revisão interna.

Dica

Confirme o produtor e a informação guardada antes de publicar. A regra de criação não altera retroactivamente as APIs pessoais já existentes.

05
Tarefa 5 de 6

Actualizar uma API e os dados associados

Mantenha o registo alinhado com o serviço e reveja as ligações aos Conjuntos de Dados.

Objectivo desta tarefaMantenha o registo alinhado com o serviço e reveja as ligações aos Conjuntos de Dados.

Como fazer

  1. 1Localize a API na sua área de gestão e abra a edição.
  2. 2Reveja o formulário preenchido e actualize a descrição, URL base, documentação ou outras informações que mudaram.
  3. 3Na secção Conjuntos de dados associados, pesquise e seleccione os conjuntos que pretende acrescentar.
  4. 4Para retirar uma associação, remova o conjunto da selecção.
  5. 5Guarde e volte a abrir o registo para confirmar as alterações e os dados associados.
Exemplo

Uma entidade actualiza a documentação funcional da API e acrescenta à selecção um Conjunto de Dados que passou a ser disponibilizado pelo serviço.

Dica

A remoção de um conjunto da selecção altera a associação ao registo da API. Não use esta acção como procedimento de eliminação do Conjunto de Dados.

06
Tarefa 6 de 6

Resolver dificuldades com uma API

Identifique se o problema afecta o registo no portal, as permissões da conta ou a comunicação com o serviço.

Objectivo desta tarefaIdentifique se o problema afecta o registo no portal, as permissões da conta ou a comunicação com o serviço.

Como fazer

  1. 1Se não consegue criar uma API, confirme a pertença à organização e o emblema Serviço público.
  2. 2Se uma chamada à API do portal falhar, compare a operação com a referência e confirme a chave e as permissões quando forem necessárias.
  3. 3Se o problema ocorrer numa API do catálogo, consulte a documentação indicada no seu registo para verificar o endereço e as condições de acesso.
  4. 4Se uma alteração ao registo não ficar guardada, registe a página, a acção e a mensagem apresentada.
  5. 5Ao pedir apoio, indique qual a API afectada e descreva o resultado esperado e o observado, omitindo credenciais e dados pessoais desnecessários.
Exemplo

Um editor não consegue iniciar a criação de uma API. Confirma que a organização seleccionada ainda não tem o emblema exigido.

Dica

Não confunda a chave da API do portal com credenciais eventualmente exigidas por outro serviço.
